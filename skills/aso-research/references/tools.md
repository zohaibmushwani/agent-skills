# Open-source ASO tools (probed 2026-11-18)
| Tool | Stores | License | Notes | Label |
|---|---|---|---|---|
| facundoolano/google-play-scraper | Play | MIT, ~3000 stars, active | the data engine: search, app, suggest, reviews, list; smoke-tested (search, suggest, app returned real data) | R |
| RankoR/aso-mcp | Play | MIT | MCP: search, details, reviews, charts, autocomplete keywords, metadata validation; README calls it an early prototype; Python 3.14+ | R/P |
| appreply-co/mcp-appstore | Play + iOS | MIT, ~78 stars | MCP: `search_app`, `get_app_details` with a `platform` argument; Node | R |
| KenanAtmaca/aso-mcp | iOS | MIT | 20 tools, own scoring, no API key | P |
| semihcihan/App-Store-Optimization-CLI | iOS | MIT, ~150 stars | real Apple popularity via a free Apple Search Ads account; MCP tool `aso_evaluate_keywords` | P |
| AsoBeast/asobeast | both | AGPL-3.0 | self-hosted tracker; study only for a closed product | study |
| AppKittie skills | both | MIT skills, paid API behind them | skill structure is reusable; live data needs their API | P |
| Registry ASO skills (various forks) | - | - | not read; one carries a Snyk "review before use" advisory | LEAD |
Not tested: the MCP servers themselves (only the scraper library was run). Paid services (Sensor Tower, AppFigures, AppFollow, FoxData) were not evaluated.
